# HaulOS

Carrier operating system for Northline Freight (demo).

**Live:** [northline-haulos-bit-ai.vercel.app](https://northline-haulos-bit-ai.vercel.app)

Office seats (owner, dispatch, HR, backoffice, safety, admin) and field phones (driver, local, helper, shop). Papers gate the next step. Truck status and trailer status are separate.

Demo passes: `T-003 / 2202`, `LOCAL / 6606`, `SHOP / 8808`, `HELPER / 7707`.

Preview only. No live SMS. Money send stays frozen.
